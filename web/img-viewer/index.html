Captura, marca y comparte

  1. Haz una captura

    Pulsa Impr Pant y elige una parte de la pantalla, una ventana o el monitor completo.

  2. Señala un detalle

    Añade una flecha o un recuadro para mostrar dónde mirar. También puedes recortar lo que sobra.

  3. Comparte la imagen

    Pega la captura en un chat, correo o documento, o guárdala para usarla después.

Encuentra la foto que buscas

Mira las imágenes de una carpeta en cuadrícula y haz doble clic en cualquiera para verla más grande. Si necesitas imágenes más pequeñas, puedes cambiar el tamaño de varias a la vez.

Preguntas frecuentes

¿Cómo empiezo?

Descarga la versión completa para Windows de 64 bits y abre el archivo. Ya incluye lo necesario para funcionar.

¿Para quién es la versión ligera?

Es la misma app en una descarga más pequeña para equipos que ya tienen .NET 10 Desktop Runtime de 64 bits.

¿Dónde encuentro mis capturas?

IMG Viewer las guarda en Descargas. Puedes elegir otra carpeta en Configuración.

¿Puedo hacer una captura mientras uso otra app?

Sí. Deja IMG Viewer abierto junto al reloj de Windows y pulsa Impr Pant cuando quieras capturar.
