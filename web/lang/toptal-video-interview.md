# Práctica de inglés — video de introducción de Toptal

Guion para el video de introducción que pide Toptal en la etapa de screening de comunicación/idioma. Toptal no publica las preguntas exactas de antemano, pero el formato es consistente: cuéntanos sobre ti, tu experiencia, y por qué Toptal.

Estas son respuestas preparadas con tus proyectos reales — practícalas hasta que salgan naturales, **no las memorices palabra por palabra** (si suena a texto leído, se nota). Dado que declaraste "Intermediate", habla a tu ritmo real, no fuerces fluidez que no tienes todavía — es mejor una respuesta simple y clara que una compleja con errores.

## "Tell us about yourself and your professional background"

```
Hi, my name is Franklin. I'm a backend developer from Peru, and I've been
working professionally since 2020. In the last few years, I've focused on
Node.js, NestJS, and React, and more recently I've also been working with
AWS and Terraform for infrastructure.

I usually work as a freelancer with clients in Latin America. For example,
I built a mobile app called Mix&Match — it's like a virtual closet for
outfits — and it reached more than ten thousand users in the first two
months. I built the backend, the mobile app, and also managed the deployment.
```

## "Why do you want to join Toptal?"

```
I want to work with better clients and more interesting projects. Right now
I work through platforms like Workana, but the projects are not always a
good match for my experience. Toptal has a reputation for serious clients
and long-term projects, and I think my experience — especially combining
backend development with cloud infrastructure — is a good fit.
```

## "Describe a challenging project you worked on"

```
One good example is a project for a company called Transpaservic, in
Colombia. I built a system for managing transport orders — a web app and a
mobile app, using React, NestJS, and MySQL. The challenge was not just the
application, it was also the infrastructure: I used Terraform to set up
AWS — EC2, RDS, S3 — and I configured Docker and a secure connection using
Cloudflare Tunnel, so we didn't need to open any ports. It's still in
production today.
```

## "What are your career goals?"

```
I want to keep growing as a full stack developer, but focus more on the
backend and cloud side, because that's where I feel I add the most value.
I also want to work with international clients on longer projects, instead
of many short ones — that's actually why I'm applying to Toptal.
```

## Consejo final

Si te preguntan algo que no esperabas, está bien decir *"Sorry, could you repeat the question?"* o *"Let me think for a second"* — es normal y no resta puntos. Lo que sí resta puntos es quedarte en silencio mucho tiempo o cambiar de tema sin responder.
