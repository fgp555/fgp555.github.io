Prueba la extensión con datos ficticios

Esta página reproduce la consulta de ofertas. No pertenece al sistema CTR real y no contiene datos de clientes ni credenciales.

  1. Instala la extensión que vas a probar en Chrome, Edge o Firefox de escritorio y recarga esta página.
  2. Selecciona Con fibra y pulsa Buscar o Enter. La extensión debe resaltar la recomendación y mostrar «¡Oportunidad única!».
  3. Cierra la alerta con Entendido. Selecciona Sin fibra y pulsa Buscar: no debe aparecer una alerta de fibra.
  4. Selecciona Otro cliente con fibra y pulsa Buscar para comprobar un segundo caso positivo.
  5. Abre el icono de la extensión para consultar la última oferta y el estado de conexión. La detección automática no requiere vincular una cuenta; la vinculación y las pruebas desde la extensión requieren una cuenta autorizada.

La página no genera alertas ni envía peticiones a Call Project por sí misma. La extensión instalada puede enviar señales de actividad y detecciones a su servidor configurado con el ID ficticio E9800001. Repetir la misma consulta puede mostrar la alerta local sin crear una nueva detección en el servidor. No ingreses datos reales.
