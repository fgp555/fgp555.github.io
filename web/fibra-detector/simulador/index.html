Esta página reproduce la consulta de ofertas. No pertenece al sistema CTR real y no contiene datos de clientes ni credenciales.

  1. Instala la versión 1.0.5 enviada a revisión y recarga esta página.
  2. Elige un caso y pulsa Buscar o Enter.
  3. Con fibra, la extensión resalta la fila y muestra «¡Oportunidad única!».
  4. Abre el icono de la extensión para declarar Venta realizada o Sin venta. Pulsa de nuevo para regresar a Pendiente.

La página no genera alertas ni envía peticiones a Call Project por sí misma. La extensión instalada puede enviar presencia, detecciones y resultados con el ID ficticio E9800001. No ingreses datos reales.
