## Junior

### Fundamentos de React Native (repaso — ya vio esto en básico)
⏳ JSX, componentes funcionales, props
⏳ Estado local (useState)
⏳ Estilos (StyleSheet, Flexbox)
⏳ Navegación básica (React Navigation: Stack, Tabs)
⏳ Listas (FlatList, ScrollView)
⏳ Manejo de imágenes y assets

### Herramientas
⏳ Expo (setup, Expo Go, expo install)
⏳ Git

### Consumo de datos
⏳ Fetch/Axios — consumo de una API REST
⏳ useEffect para llamadas asíncronas
⏳ Debugging básico (consola, React Native Debugger)

---

## Mid (Semi Senior)

### TypeScript
⏳ Tipado de props e interfaces
⏳ Tipos genéricos aplicados a componentes y hooks

### Estado y datos avanzados
⏳ Context API
⏳ TanStack Query (manejo de datos asíncronos y caché)
⏳ AsyncStorage (persistencia local simple)

### Autenticación
⏳ OAuth (Google / Apple Sign-In)
⏳ JWT y manejo de sesión

### Funcionalidades nativas comunes
⏳ Push notifications
⏳ Cámara / selector de imágenes
⏳ Permisos del dispositivo (ubicación, cámara, notificaciones)

### Testing
⏳ Jest — tests unitarios básicos
⏳ React Native Testing Library

### Publicación
⏳ Build con EAS Build
⏳ Publicación en Google Play Store
⏳ Publicación en Apple App Store

---

## Senior

### Arquitectura
⏳ Clean Architecture / MVVM adaptado a RN
⏳ Manejo de estado global robusto (Redux Toolkit, Zustand o MobX)
⏳ Monorepos (Turborepo, Nx o pnpm workspaces)

### Almacenamiento y offline
⏳ SQLite, Realm o MMKV
⏳ Lógica offline-first (caché local, colas de sincronización, reintentos)

### Nativo y performance
⏳ Módulos nativos / bridges personalizados (Android/iOS)
⏳ Optimización de performance (renders innecesarios, listas grandes, memoria)

### CI/CD y calidad mobile
⏳ Fastlane, Bitrise o GitHub Actions específico para mobile (build, firma, distribución)
⏳ Firebase App Distribution
⏳ Crash reporting (Sentry o Crashlytics)
⏳ Seguridad mobile (OWASP MASVS, almacenamiento seguro de tokens)

### Liderazgo técnico
⏳ Code reviews
⏳ Documentar decisiones de arquitectura (ADRs)
⏳ Mentoría a desarrolladores junior/mid
