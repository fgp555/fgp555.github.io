## Fase 1: Fundamentos de Java (si aún no los dominas)

- Sintaxis, POO (clases, herencia, interfaces, polimorfismo)
- Colecciones (List, Map, Set)
- Manejo de excepciones
- Streams y expresiones lambda (Java 8+)
- Maven o Gradle (gestión de dependencias)

## Fase 2: Spring Boot — Core

- Inyección de dependencias (@Autowired, @Component, @Service, @Repository)
- Spring MVC: crear controladores REST (@RestController, @GetMapping, @PostMapping, etc.)
- Spring Data JPA: conexión a bases de datos relacionales (Postgres, MySQL, SQL Server)
- Validaciones (@Valid, Bean Validation)
- Manejo de excepciones global (@ControllerAdvice)
- application.properties / application.yml

## Fase 3: Seguridad y autenticación

- Spring Security básico
- **OAuth2 / JWT** — esto aparece en ambas ofertas, es casi obligatorio hoy en día
- Manejo de roles y permisos

## Fase 4: Testing

- **JUnit 5** y **Mockito** (ambos mencionados explícitamente en la oferta senior)
- Pruebas unitarias vs pruebas de integración
- Testcontainers (opcional pero valorado)

## Fase 5: Microservicios y APIs

- Diseño de APIs REST (buenas prácticas, versionado, códigos HTTP correctos)
- Comunicación entre microservicios (REST clients, Feign)
- Documentación con Swagger/OpenAPI

## Fase 6: Bases de datos adicionales

- Redis (caché) — mencionado en la segunda oferta
- Bases NoSQL básicas (MongoDB es buen punto de partida)

## Fase 7: Contenedores y DevOps básico

- **Docker**: crear un Dockerfile para tu app Spring Boot
- Docker Compose (levantar app + base de datos juntos)
- Nociones de **Kubernetes** (conceptos: pods, deployments, services)
- CI/CD básico (GitHub Actions es más fácil para empezar que Jenkins)

## Fase 8: Arquitectura y eventos (nivel más avanzado)

- **Apache Kafka** / arquitectura orientada a eventos
- Domain Driven Design (DDD) — conceptos básicos
- Arquitectura Hexagonal / Clean Architecture
- Clean Code y TDD

## Fase 9: Quarkus (transición natural)

- Una vez domines Spring Boot, aprender Quarkus es rápido porque comparte conceptos
- Enfócate en las diferencias: arranque nativo con GraalVM, extensiones vs starters
