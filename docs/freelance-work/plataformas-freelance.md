# Plataformas de freelance — mapa de estrategia

Perfil: full stack + DevOps/Cloud, con experiencia real en producción (NestJS, AWS, Terraform, Docker) y clientes previos en Argentina y Colombia.

## 🌎 Volumen + mercado LatAm (donde ya hay tracción)

- **Workana** — la plataforma más grande para freelancers hispanohablantes, mucha demanda de dev full stack.
- **Upwork** — mercado masivo, cliente internacional (USD). El combo NestJS + AWS + Terraform destaca sobre el perfil promedio.

## 💎 Prestigio + mejores tarifas (vetting estricto, pagan mucho más)

- **Toptal** — acepta solo el top 3% de aplicantes, apunta a clientes enterprise con compromisos largos. Tarifas típicas de $220+/hora para developers senior. No cobra comisión al freelancer (el margen lo pone el cliente). El stack de DevOps (Terraform, AWS, Docker) es exactamente lo que buscan.
- **Lemon.io** — alternativa a Upwork enfocada en developers full stack senior pre-evaluados, buen fit para este perfil.
- **CloudDevs** — talento de software vetted, para firmas que necesitan ingenieros con skills técnicos profundos. Bueno para posicionarse por el lado cloud/AWS.

## 🆓 Sin comisión, construcción de marca personal

- **Contra** — más de 1 millón de freelancers, cero comisión de plataforma. Sirve como portafolio + generación de leads paralela.

## Recomendación concreta

Dado que ya hay proyectos reales en producción (no se empieza de cero):

1. **Aplicar a Toptal ahora** — la experiencia en Terraform/AWS/arquitectura es justo lo que filtran; el proceso es largo pero una vez dentro las tarifas son mucho mejores.
2. **Mantener Workana activo** — para no depender de un solo canal mientras Toptal evalúa (el proceso puede tardar semanas).
3. **Crear perfil en Contra** — gratis, cero comisión, portafolio permanente para compartir en LinkedIn/GitHub.
