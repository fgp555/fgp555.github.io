Descripción completa del empleo
¿A quién buscamos?

Buscamos un DevOps Engineer con experiencia sólida en infraestructura cloud, automatización, contenedores y prácticas DevOps, que impulse la eficiencia, escalabilidad, seguridad y confiabilidad de los entornos tecnológicos de Kashio. Este rol será responsable de implementar y mantener infraestructura como código, administrar servicios cloud en AWS, optimizar pipelines CI/CD, gestionar plataformas de contenedores y fortalecer las capacidades de observabilidad y monitoreo de nuestras soluciones.

Funciones Principales

· Implementar, administrar y optimizar servicios cloud en AWS, incluyendo EC2, EKS, ECS, S3, RDS, SQS, API Gateway y otros servicios relacionados.

· Gestionar plataformas de contenedores utilizando Kubernetes, preferentemente EKS, así como herramientas como kubectl, Helm charts y Docker.

· Diseñar, aprovisionar y mantener infraestructura como código mediante Terraform, CloudFormation u otras herramientas equivalentes.

· Desarrollar y mantener módulos, variables y buenas prácticas de versionado para la gestión eficiente de recursos cloud.

· Configurar, mantener y optimizar pipelines CI/CD en Bitbucket Pipelines, GitHub Actions, GitLab CI, Jenkins u otras herramientas similares.

· Implementar prácticas GitOps con ArgoCD u otras herramientas relacionadas para mejorar el despliegue y control de cambios.

· Automatizar tareas operativas mediante scripting en Bash, Python u otros lenguajes similares.

· Implementar y gestionar herramientas de monitoreo, observabilidad, métricas, alertas y logging centralizado, tales como Prometheus, Grafana, CloudWatch, ELK o Loki.

· Participar en la mejora continua de la seguridad, disponibilidad, escalabilidad y confiabilidad de los entornos cloud y de microservicios.

· Colaborar con los equipos de Tecnología, Producto y Seguridad para asegurar despliegues estables, trazables y alineados a las necesidades del negocio.

Requisitos del Puesto

Formación Académica

Profesional en Ingeniería de Sistemas, Ingeniería Informática, Ingeniería Electrónica, Computación, Telecomunicaciones o carreras afines.

Experiencia Laboral

· Mínimo 3 años de experiencia trabajando con servicios cloud de AWS.

· Mínimo 3 años de experiencia utilizando infraestructura como código.

· Mínimo 3 años de experiencia utilizando herramientas Atlassian como Jira, Confluence y Bitbucket.

· Mínimo 3 años de experiencia en metodologías DevOps sobre entornos cloud.

Conocimientos Técnicos

· AWS: EC2, EKS, ECS, S3, RDS, SQS, API Gateway, CloudWatch, VPC, IAM y Security Groups.

· Kubernetes, EKS, kubectl, Helm charts y buenas prácticas de despliegue de workloads.

· Docker y buenas prácticas de contenerización.

· Terraform, CloudFormation, infraestructura como código, módulos, variables y versionado.

· CI/CD en Bitbucket Pipelines, GitHub Actions, GitLab CI, Jenkins o herramientas similares.

· ArgoCD, GitOps, scripting en Bash, Python o lenguajes similares para automatización.

· Monitoreo y observabilidad con Prometheus, Grafana, CloudWatch, ELK, Loki u otras herramientas de logging centralizado.

· Deseable conocimiento en Lambda Functions, arquitecturas serverless, prácticas SRE, SLI, SLO, SLA, telemetría e IA aplicada.

Habilidades y Competencias

· Comunicación efectiva y capacidad para explicar temas técnicos de manera clara.

· Trabajo colaborativo con equipos multidisciplinarios.

· Capacidad para compartir conocimiento y promover buenas prácticas dentro del equipo.

· Pensamiento analítico, orientación a la mejora continua y enfoque en la solución de problemas.

· Autonomía, responsabilidad y criterio técnico para gestionar entornos críticos.

· Proactividad, sentido de urgencia y compromiso con la disponibilidad, seguridad y escalabilidad de las plataformas.
